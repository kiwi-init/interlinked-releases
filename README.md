# Interlinked releases

Signed and notarized downloads of [Interlinked](https://github.com/kiwi-init/interlinked), a browser for macOS. It needs macOS 26 on an Apple silicon Mac.

Install with Homebrew:

```sh
brew install --cask kiwi-init/tap/interlinked
```

Or download the DMG from [Releases](https://github.com/kiwi-init/interlinked-releases/releases). Each release lists its SHA-256.

Versions are dates, YYYY.M.PATCH. The source and the release scripts are in [kiwi-init/interlinked](https://github.com/kiwi-init/interlinked).
